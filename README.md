# agugentile.github.io

Source of my portfolio: https://agugentile.github.io

A static page (no framework, self-hosted fonts, no trackers). It is generated from the same data as my resume, so the figures on the page match the PDF. `public/` is what gets deployed; the GitHub Actions workflow in `.github/workflows/pages.yml` publishes it to GitHub Pages on every push to `main`.
